Patient Clinic Simulator

Software

C++ CMake

A command-line simulation of a walk-in medical clinic, modelling the patient triage and doctor scheduling. The program manages a nurse and up to three doctors, each maintaining their own patient waitlist using a custom-built linked list. The simulation implements two scheduling strategies: First In First Out (FIFO) and Shortest Job Next (SJN), to demonstrate how queue discipline affects overall patient wait time.

Built using object-oriented design with class inheritance, custom ADTs, and a simulated clock system. All data structures were implemented from scratch, no standard libraries were used.
